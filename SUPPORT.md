# Support

Four channels, roughly in the order that gets you an answer fastest.

| You have | Go to |
| --- | --- |
| A question about how to do something | [Discord](https://discord.usetheo.dev/) — the fastest answer, and someone else usually had the same question |
| A reference question about the API | [usetheo.dev/docs](https://usetheo.dev/docs), and the exported TypeScript types — they are the contract |
| A bug, or docs that led you wrong | An issue in the repository that owns the code ([all of them](https://github.com/orgs/usetheokit/repositories)) |
| A security problem | **Not an issue.** Follow [SECURITY.md](./SECURITY.md) |

## Filing something we can act on

A report gets fixed faster when it arrives with the version, the platform, and the
smallest reproduction you have. The issue forms ask for exactly that and nothing more —
if a field feels pointless for your case, say why instead of leaving it blank.

If the docs could not answer your question, that is a documentation defect and worth its
own issue. We would rather fix the page than answer the question twice.

## What we do not promise

These are open-source projects. Issues are triaged as maintainers have time, and there is
no SLA on a free channel. Security reports are the exception: those get acknowledged within
three business days, and if you hear nothing, the report did not reach us — ping the thread.
